# Pyre Alley

Full-colour Python 3 neon skee-ball arcade for [ElbowOS](https://x.com/ElbowOS).

Charge a gold ember up a plum alley.
Bank off amber rails.
Drop into 20 / 30 / 50 / 100 pyre cups for combos.
A / D aim. Hold Space / W to charge. Release to launch.

## Play

```
pip install -r requirements.txt
python3 pyre_alley.py --play
```

## Record a 9:16 reel

```
python3 pyre_alley.py --record
```
